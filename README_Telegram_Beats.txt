TELEGRAM BEATS — версия с сервером поиска и аудиопотоков

Почему нужен сервер
-------------------
Если открыть один HTML-файл напрямую (file://), браузер и удалённые сервисы могут блокировать часть запросов. Эта версия запускается через Node.js: сервер выполняет поиск в Audius и Internet Archive, возвращает список треков и передаёт аудио с поддержкой Range/перемотки. API-ключи для этих двух источников не требуются.

БЫСТРЫЙ ЗАПУСК НА КОМПЬЮТЕРЕ
---------------------------
1. Установи Node.js 20 или новее: https://nodejs.org/
2. Распакуй архив в отдельную папку.
3. В этой папке открой терминал/командную строку.
4. Выполни: npm start
5. Открой в браузере: http://localhost:3000
6. Открой «Источники и диагностика» → «Проверить соединение».

Никаких Jamendo Client ID, SoundCloud токенов или YouTube API-ключей не нужно.

РАЗМЕЩЕНИЕ В ИНТЕРНЕТЕ
----------------------
Проект содержит render.yaml для развёртывания на Render:
1. Загрузи файлы проекта в свой GitHub-репозиторий.
2. На https://render.com создай New → Web Service и подключи репозиторий.
3. Build command: npm install
4. Start command: npm start
5. После развёртывания открой выданный HTTPS-адрес.

Важно: бесплатный хостинг может засыпать после бездействия. Первый запуск после сна может занять время.

ЧТО ПОДДЕРЖИВАЕТСЯ
------------------
- Поиск и случайная «Моя волна» через Audius и Internet Archive.
- Проксирование аудио с передачей Range-запросов, что позволяет перематывать поток, если исходный источник это поддерживает.
- Локальная библиотека MP3, плейлисты, удаление треков, изменение названия/исполнителя и обложки.
- Диагностика доступности источников.

ОГРАНИЧЕНИЯ
-----------
- Нельзя гарантировать наличие любой конкретной песни: каталоги не содержат все популярные хиты, а отдельные треки могут быть удалены, заблокированы или не воспроизводиться в конкретной сети.
- Кнопка проверки проверяет доступность API из среды сервера, а не гарантирует доступность каждого аудиофайла.
- Не размещай сервер без защиты на публичной сети, если собираешься менять его код для добавления произвольных URL. Текущий прокси ограничен двумя источниками.
